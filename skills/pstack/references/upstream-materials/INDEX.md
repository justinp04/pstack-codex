# Upstream reference material

The original tutorials, artwork, agent prompts, and dormant Benny automation
pack are preserved here for reference and comparison. Markdown source uses
.md.txt so it does not register skills or masquerade as current Codex workflow
instructions. These files describe the pinned upstream release, including
Cursor APIs that may be unavailable. Use the adapted runtime/guide procedures
for execution. Do not execute historical commands or mutate external systems
merely because an example says to. Benny's triage/dedupe/thread-coordinate/
existing-fix/reproduction/verification templates remain available as source;
automatic Slack/routine triggers are not claimed as working Codex features.
The .cursor-plugin manifest is not a Codex manifest and is intentionally not
installed. Source revision/attribution are in ../provenance.md.
