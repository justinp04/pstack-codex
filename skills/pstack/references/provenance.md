# Provenance and fidelity

Derived from [Lauren Tan's pstack](https://github.com/cursor/plugins/tree/1dcc2bacde73ddd284803b7af28164d0436198fc/pstack).
Pinned revision is 1dcc2bacde73ddd284803b7af28164d0436198fc; upstream version
0.15.21. Live upstream main matched this revision at the 2026-10-13 fidelity
audit. MIT attribution remains in root LICENSE. This is a local unofficial
Codex port with no automatic upstream updates.

The initial port retained all guide/playbook filenames but simplified several
procedures too far. The fidelity audit restored setup budget/role choices and
verification-map offer; automate-me personal-style mining/authoring; Recall's
shared-record/live-state/output contracts; Reflect's structural-routing phases;
the full help map; complete planning skeleton and ten live lanes; PR briefing
template; babysit frontier/topology/CI safeguards; orchestration pilot/rolling
queues/standing-orders/failure policies; autopilot durability/countersigns;
fresh-agent reuse conditions; and autonomous-run predicate/pivot discipline.

All 52 top-level upstream skill guides (51 specialists plus the mode), all 23
playbook categories, and the upstream specialist references are retained behind
one discoverable skill. All 21 original poteto-mode helper implementation/test/
package files are restored as optional tools. Plan-marker strings and worktree
chat discovery/classification were adapted; helper dependencies are explicit.
Original tutorials/artwork/agents and the dormant Benny extension are preserved
as historical source in upstream-materials, not active Cursor instructions.

Intentional Codex differences remain: actual tool/model capability mapping,
inherited models absent explicit preferences, bounded concurrency and real
requested automation instead of /loop/cloud assumptions; no private transcript
path inference; user-scoped PR/message/merge authority; nondestructive dirty-work
preservation; preserving unresolved safety comments/suppressions; supported
webhook integration only; exact-base/head reverification after every change,
without upstream patch-ID reuse waivers. Optional Graphite frontier resolution
remains conditional on real gt metadata, with a forge/git ledger fallback.

File presence alone is not semantic parity. The audit records each meaningful
restoration/adaptation, and validation combines static comparison, helper tests,
plan completeness rejection, classifier checks, and isolated setup execution.
Real forge merges, UI/webhook integrations, remote fleets, Benny triggers, and
execution of every playbook are not implied by those checks.
