# Arena

1. Frame the common task and artifact. Derive 3-6 concrete gradeable rubric
   criteria, kept from the candidates. Ground existing constraints first.
2. Spawn at least two fresh independent candidates with structurally distinct
   directions, identical task scope, separate output paths/checkouts, and the
   runtime contract. Inherit models unless actual overrides are authorized.
   Queue within host concurrency. Record dropouts as gaps.
3. After candidate artifacts are complete, give a fresh read-only cross-judge
   the rubric and artifacts by sanitized label. It scores every criterion
   and recommends a base. Do not expose candidate model names. Disclose
   same-model review where provider diversity is unavailable.
4. Read every candidate, score it against the rubric, and compare the judge's
   rationale. Resolve disagreements from evidence. Prefer the cleanest
   boundary and smallest adequate API when outcomes tie.
5. Select the base and graft only the strongest compatible parts of other
   candidates. Do not average incompatible designs. If directions diverge
   because the brief was vague, reframe and repeat.
6. Verify the synthesized artifact on its actual surface. Keep evidence,
   independent verdict, source candidates, chosen/rejected parts, rationale,
   and dropouts. A missing required candidate or check remains open.

Candidate rationale names alternatives considered and rejected. The cross-judge
receives grounding, rubric, and all complete artifacts, and returns criterion
scores, evidenced findings, ranked base recommendation, and rationale. When
candidates converge, report consensus and skip needless grafts. A verification
failure means the frame was wrong (reframe) or a useful losing candidate part
was missed (revisit grafting); do not patch around a mistaken design.
